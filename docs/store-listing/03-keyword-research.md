## Placement rules

- Google Play indexes title, short and long description (no keyword field). Repeat primary terms 3-5 times naturally in the long description; never stuff.
- App Store indexes name, subtitle, keyword field only. Do not repeat words across them. Use singular forms; the store handles plurals.
- Turkish listing is a separate locale on both stores: set TR as the default or add it as a localization and get the Turkish keyword field indexed. On iOS, TR storefront also indexes some English keywords; keep the English set in the EN locale.
- Avoid competitor brand names in metadata (policy rejection risk).
